# Infinity Player — نسخة الجوال 1.0.3

مشروع مستقل عن «هدف»، بواجهة عربية داكنة. هذه حزمة كود مصدر للآيفون والآيباد وأندرويد، وليست ملف تثبيت موقّعًا أو تطبيقًا منشورًا. لا تتضمن قنوات أو اشتراكات محتوى. تفضّل HTTPS، وتدعم HTTP بعد موافقة صريحة لكل مصدر.

## الوظائف الموجودة

- إضافة وتعديل وحذف عشرة مصادر: Xtream، رابط M3U، رابط فيديو MP4/HLS.
- التحقق من حساب Xtream قبل حفظه، وعرض القنوات والأفلام والمسلسلات ثم حلقات المسلسل.
- تصنيفات وبحث ومفضلة (40 عنصرًا لكل مصدر).
- مشغّل expo-video بأزرار النظام، ملء الشاشة، تقديم/إرجاع، واختيار المسارات المتاحة.
- حفظ موضع آخر عشرة عناصر، واستئناف الفيديو عند فتحه مجددًا (باستثناء البث المباشر).
- تخزين بيانات المصادر والمفضلة وسجل المشاهدة باستخدام SecureStore على الجهاز.
- شروط وخصوصية داخل التطبيق، وموافقة المستخدم، وحذف المصدر أو جميع البيانات.
- فيديو تجريبي محلي أصلي لا يتصل بمزوّد محتوى.
- إعدادات EAS للبناء السحابي من ويندوز.

## التشغيل من ويندوز

ثبّت Node.js 22 LTS. فك الضغط وافتح PowerShell داخل مجلد `infinity-player`:

```powershell
npm ci
npx expo install --check
npm test
```

المشروع يستخدم Expo SDK 54. لا تفترض أن أحدث Expo Go على الآيفون يدعم هذا الإصدار. الطريقة المفضلة للتجربة هي بناء Preview مستقل عبر EAS؛ لا يحتاج Metro بعد التثبيت.

```powershell
npm install -g eas-cli
eas login
eas init
eas build:configure
eas device:create
eas build --platform ios --profile preview
```

- سجل الدخول لحساب Expo الخاص بك.
- `eas init` يربط المشروع بحسابك ويضيف معرّف EAS الحقيقي؛ لا يوجد معرّف مختلق في الحزمة.
- تأكد من معرّف الحزمة `com.khalidalnashri.infinityplayer` قبل أول بناء؛ غيّره إذا كان مستخدمًا بالفعل.
- سجّل الآيفون في فريق مطوّر آبل عندما تطلب الخدمة ذلك. بيانات حساب آبل تُدخل في أداة EAS الرسمية على جهازك، لا في المحادثة.
- افتح رابط البناء الناتج لتثبيت نسخة الاختبار على الجهاز المسجّل. قد تترتب تكلفة/حدود استخدام لدى خدمة البناء.

أندرويد (APK تجريبي):

```powershell
eas build --platform android --profile preview
```

للمحاكي المحلي أو Expo Go المتوافق فقط:

```powershell
npx expo start
```

## رفع نسخة TestFlight

بعد استكمال إعدادات الناشر واختبار الجهاز:

```powershell
eas build --platform ios --profile production
eas submit --platform ios --latest
```

سيطلب EAS ربط التطبيق الصحيح في App Store Connect. أنشئ سجلًا جديدًا باسم Infinity Player وبمعرّف حزمته؛ لا تختَر تطبيق «هدف». رفع TestFlight لا يعني تقديم App Review أو النشر تلقائيًا.

## تجربة البداية

1. وافق على الشروط والخصوصية.
2. اختر «جرّب المشغّل بفيديو تجريبي» ثم اضغط الفيديو. يجب أن يظهر فيديو أصلي مدته عشر ثوانٍ مع نغمة خفيفة.
3. أضف مصدر HTTPS تملك حق استخدامه؛ لا ترسل بياناته في المحادثة.
4. اختبر التصنيفات والبحث والمفضلة وفتح حلقة، والخروج من المشغّل ثم الاستئناف.
5. أغلق التطبيق وأعد فتحه للتحقق من حفظ المصدر والمفضلة.
6. احذف المصدر وتأكد من زوال بياناته. اختبر حالات انتهاء الاشتراك وانقطاع الإنترنت.

## قبل App Review

راجع `docs/APPLE-RELEASE.md`. يجب إضافة بريد دعم حقيقي ورابط سياسة خصوصية منشورة في `app.json > expo.extra`، وتعبئة إفصاحات App Store Connect تبعًا لسلوك النسخة النهائية. الحزمة تحتوي مسودة سياسة داخل التطبيق؛ لا يوجد رابط سياسة مستضاف بعد.

لا تتضمن هذه النسخة مدفوعات أو أكواد تفعيل. عند إضافة ميزات مدفوعة، يلزم تنفيذ StoreKit والتحقق من الشراء والاستعادة وفق القواعد السارية في الأسواق المستهدفة.

## حدود هذه النسخة

- تم تجهيز نواة الجوال، وليس إصدارًا جاهزًا لكل المتاجر. لم تُبنَ أو تُوقّع IPA/APK هنا، ولم يُجرَ اختبار أجهزة فعلي.
- لا توجد لوحة إدارة أو حساب سحابي أو مزامنة أجهزة أو اشتراكات للمشغّل في هذه الحزمة.
- Apple TV وAndroid TV يحتاجان إعدادات React Native TV وتنقّل ريموت واختبارات مستقلة. سامسونج Tizen وLG webOS يحتاجان تطبيقات منفصلة. إصدارات الكمبيوتر والمتصفح غير مشمولة في هذا الإصدار.
- لا يدعم DRM أو تمرير رؤوس مخصّصة من M3U أو تنزيل/تسجيل البث أو EPG في هذا الإصدار.
- قد لا تعمل TS/MKV وبعض مسارات الصوت على iOS؛ دعم الصيغ تابع لمشغّل النظام. نطلب بث HLS للقنوات من Xtream.
- حد القائمة 30 ألف عنصر/12 ميغابايت. الحد بعد التحميل للنص أيضًا؛ ليس تحميلًا متدفقًا. لا تستورد ملفات ضخمة غير موثوقة.
- القوائم النسبية مسموحة إذا تحولت إلى HTTP/HTTPS وفق موافقة المصدر. لا نعيد توجيه اتصالات القائمة عمدًا؛ استخدم الرابط النهائي من المصدر. توافق سلوك التحويلات يتطلب اختبارًا على الجهاز.
- توافق واجهة Xtream يختلف بين المزوّدين؛ يلزم اختبار بمصدر مصرّح حقيقي.
- حذف التطبيق وحده على iOS قد لا يمسح عناصر Keychain؛ استخدم حذف المصدر أو حذف جميع البيانات أولًا.

## تحديث 1.0.2: دعم HTTP

في إضافة أو تعديل المصدر، فعّل «السماح بـ HTTP لهذا المصدر» واقبل تنبيه النقل غير المشفّر قبل الحفظ. لا يُحفظ اشتراك المستخدم في ملفات المشروع. يتطلب التحديث بناءً أصليًا جديدًا عبر EAS؛ تحديث JavaScript وحده لا يضيف صلاحيات الشبكة.

استثناء ATS على iOS عام لأن المستخدم يكتب نطاق المصدر بنفسه. يظل التحقق الافتراضي داخل التطبيق HTTPS، لكن الاستثناء يخفف حماية النظام على مستوى التطبيق؛ يجب تبرير ضرورته لفريق آبل. لا يضمن هذا الموافقة.

## تحديث 1.0.2

- مشغّل مستقل من حيث العلامة والمحتوى، مع الاحتفاظ بدعم Xtream وM3U والبث المباشر. لا تتضمن النسخة مزودًا أو اشتراكًا أو قنوات مرفقة.
- إضافة فيديو من تطبيق الملفات؛ يحفظ التطبيق نسخة محلية داخل مساحة التطبيق، ويحتفظ بالملف الأصلي. حذف المصدر يحذف النسخة المستوردة فقط.
- حفظ موضع المشاهدة دوريًا كل 15 ثانية، وعند انتقال التطبيق للخلفية والخروج وإعادة المحاولة. انتهاء الفيديو يمسح موضع الاستئناف.
- فلتر متابعة المشاهدة داخل القسم الحالي؛ لحلقات المسلسلات افتح المسلسل أولًا.
- تصفير البحث والتصنيف والمفضلة عند فتح حلقات مسلسل حتى لا تُحجب الحلقات بالفلتر السابق.
- المرجع ibo Pro Player يُستخدم لفكرة مشغّل يضيف المستخدم مصادره؛ لا يوجد نسخ لاسمه أو شعاره أو ارتباط به.
- دعم البث يُذكر بصراحة في بيانات المراجعة. تغيير الاسم لا يضمن موافقة آبل؛ يلزم اختبار المحتوى المصرّح به واستكمال بيانات الناشر.

بعد تنزيل التحديث: فك الضغط في مجلد جديد ثم نفّذ `npm ci`، وأعد ربط مشروع Infinity Player نفسه عند وجوده. لا تربطه بتطبيق BBM أو هدف.

## تحديث 1.0.3 — واجهة المكتبة

- أزرار القنوات والأفلام والمسلسلات مباشرة داخل بطاقة مصدر Xtream.
- أغلفة الأفلام والمسلسلات في شبكة من عمودين إلى خمسة حسب عرض الشاشة، وشعارات القنوات والقوائم عندما يوفّرها المصدر.
- بديل مرئي عند عدم توفر الصورة أو فشل تحميلها، مع البحث والتصنيفات والمفضلة.
- روابط الصور تخضع لشرط HTTPS أو موافقة HTTP الخاصة بالمصدر. تُحمّل الصور من الروابط التي يحددها المصدر؛ توضّح سياسة الخصوصية هذا الاتصال.
- تظل المفضلة ومتابعة المشاهدة داخل القسم الحالي؛ دعم M3U هنا يعرض العناصر في قائمة واحدة، وM3U8 للبث المباشر يضاف كرابط فيديو.
- لا تتضمن هذه المرحلة Apple TV أو VLC أو رقابة أبوية أو تفاصيل الممثلين والتقييمات. هذه وظائف لاحقة تحتاج تطويرًا واختبارًا مستقلًا.
- النسخة تتطلب بناء EAS جديدًا لتجربتها على iPhone. لا علاقة لها ببناء تطبيق BBM.
