# نطاق المنصات

| المنصة | الموجود في هذه الحزمة | المتبقي |
|---|---|---|
| iPhone / iPad | واجهة React Native ومشغّل وتخزين آمن وإعدادات EAS | توقيع وبناء وتجربة فعلية وملف المتجر |
| Android mobile | نفس الشاشات ومشغّل expo-video وAPK profile | بناء واختبار أجهزة ومتجر |
| Apple TV / Android TV / Fire TV | منطق القوائم قابل لإعادة الاستخدام | React Native TV، إعدادات الأصلية، الريموت والتركيز وتجارب التشغيل |
| Samsung / LG | مواصفات ومنطق يمكن نقله | تطبيق Tizen وwebOS، مشغّلات المنصة، حزم وتوقيع ومراجعة |
| Windows / macOS / browser | لا توجد نسخة مضمنة | اختيار حزمة سطح المكتب/المتصفح وتنفيذ تخزين ومشغّل مناسبين |
| لوحة الإدارة | غير مضمنة | حسابات وخادم وتفويض وصلاحيات ومدفوعات وربط الأجهزة |

لا تمثل هذه الحزمة اكتمال هدف «كل المنصات». البداية المتفق عليها نسخة الجوال، مع إعطاء آبل الأولوية.
